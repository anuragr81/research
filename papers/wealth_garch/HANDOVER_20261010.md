# Handover: asymmetric capital-buffer QVI — empirical companion

For a Claude Code session picking this up cold. Read all of it before running
anything. Everything stated here as a number has been re-derived from primary
sources and is reproducible with the two scripts in this bundle.

Date of handover: 10 October 2026.

---

## 1. What this project is

A theory paper on optimal bank recapitalisation as impulse control (a QVI with
a fixed cost K and a regulatory constraint), plus an empirical companion
testing its predictions against FDIC Call Report data 2015–2024.

The theory paper is **closed**. The empirical companion is where the remaining
work is, and it is close to a stopping point.

---

## 2. Current state in one paragraph

Two substantive empirical results are established and one question is open.
The model's **corner solution is rejected** on its own regulatory basis: it
predicts banks operate at their risk-based capital minimum, and they hold
3.34× it. The **shape test is confirmed**: issuance behaviour is neither
fixed-size nor exactly-targeted, which is the qualitative signature the
model's control structure implies. The **diffusion parameter σ remains
untested**, because Call Report book values do not measure asset value on the
basis σ is specified on, and a 4.1× residual survives after correcting for the
rejected corner solution.

## 7. Settled questions — do not re-open these

These cost real time to establish. Each is a conclusion, not a hypothesis.

**1. The σ-ratio test is void, not failed.** Along the solved policy,
σ(x) = κ₁(x−1) below the regime switch x̄ = 1.167647 and κ₃(x−a₂) above.
Within a single constraint branch the ratio is

```
sigma(x_post) / sigma(x_pre) = (x_post - a) / (x_pre - a)
```

with κ cancelling identically. The ratio therefore carries no information
about σ at all. It has content only when the two states straddle x̄, which is
a fact about the calibration, and the calibration is what fails. Evaluated at
the model's own states it gives 6.62; at the states banks actually occupy it
gives 1.129, inside the data interval [1.087, 1.748]. Neither figure is a
test. The entire regime-switch investigation (Option 4) answered a question
already vacated by the levels result. Its two algebraic results stand on their
own as mathematics — x̄ − 1 = a₁(1−a₂)/(a₃−a₁) > 0 for every admissible
triple, and the solvency branch binds on all of (1, x̄) so a₃ is inert there —
but they are not empirical findings.

**2. π is observed. It is `RWAJT/ASSET`.** The constraint
u(x) ≤ (x−1)/a₁ rearranges with no modelling choice to E/RWA ≥ a₁, and
a₁ = 0.045 is exactly the Basel III CET1 minimum. This is not a proxy. An
earlier version of the key wrongly marked π and a₁ as NOT OBSERVED and
concluded the model was untested; that conclusion was wrong and the corner
solution is a genuine rejection. One precision caveat to carry: the pulled
field `RBCT1J` is Tier 1 capital, minimum 6%, not CET1 specifically. Tier 1 ⊇
CET1, so Tier1/RWA is an upper bound on CET1/RWA. The finding holds under
either minimum — 3.34× against a₁, 2.51× against the Tier 1 minimum.

**3. The pi_cap recalibration was run and fails.** Four caps
{0.5, 0.75, 1.0, 2.0}, all converged. No cap brings the model into range,
because the requirements are disjoint *within the tested range*, not merely
unmet at the grid points: bringing σ into range needs cap ≈ 0.17, placing S in
the empirical band needs cap ∈ [0.89, 1.39]. At cap 0.5, σ is at the edge of
range but S has fallen to 1.0481, below the band; at cap 1.0, S is in band at
1.0999 but σ is 6.1× too large. The trigger sits at the boundary s = 1.0000 at
every cap including the loosest. Do not re-run this hoping for a different
answer.

**4. The σ excess is the parameter, not the leverage bound.** At π = 1 — no
leverage at all, every asset risky — the model is still 6.1× more volatile
than measured. The asset volatility that reconciles at π = 1 is 0.01337
against the model's σ = 0.08. 1.3% is a book-value asset volatility; 8% is an
economic-value one.

**5. The MUTUAL invariance leg is definitionally dead.** Mutual institutions
have no common stock, so any issuance-defined event set selects MUTUAL = 0
almost surely — it appears on 2 of 528 event banks. No re-pull or threshold
change fixes this. It is not a power problem.

**6. Never quote −b_pre/x̄ as a targeting share.** Under the accounting
structure it depends on the variance of the untargeted flow term and is not a
mixing weight bounded by 1. Report the slope pair against both benchmarks.

**7. The entrance-boundary argument is scoped to s = 1 exactly.** A feasible
trigger sits above x̄ in the liquidity branch, where σ is bounded away from
zero, so the probability-zero conclusion does not extend to s = 1 + ε. The
scale-function rarity factor exp(2b(1)/(κ₁²ε)) at ε of order the grid spacing
is only O(1)–O(10).

**8. Levels, as a comparison, are not a clean third test.** They inherit both
the rejected corner solution and the untested σ, so they are not independent
of items 2 and 4.

## 8. The open decision

σ is the only open item, and the question is whether to test it.

Testing it requires an economic-value state variable, `x_econ = 1 + E_mkt/L`,
which means a market-equity panel linked to the FDIC panel. The linkage is
feasible and was established: CERT → FED_RSSD → parent RSSD (NIC Relationships
file) → the NY Fed CRSP-FRB link table, which is free and covers 1,495 links
to 2024Q3. A coverage probe returned **681 of 6,581 panel banks listed**,
comfortably above the 100 needed, but only **26 of 211 repeat issuers**, so
the event-based designs stay on the book basis regardless. That costs nothing,
since the shape test is already valid there.

Without WRDS the price route is SEC EDGAR for shares outstanding plus a free
price source, which needs CIK resolution. There is **no free official
RSSD/PERMCO → CIK crosswalk**; the only path is matching holding-company legal
names from the NIC Attributes table against SEC's `company_tickers.json`.
Matching the *bank's* name instead is structurally wrong and was the cause of
several bad matches — the holding company often shares no words with its bank
("Heritage Bank USA" → "HopFed Bancorp").

**The three options:**

1. Rewrite `EMPIRICAL_KEY` from §3 and §7 and stop. Gives a complete, honest
   statement: one confirmed finding, one rejection, σ recorded as untestable
   on this data.
2. Rebuild the σ chain (four scripts) and spend a manual CIK-confirmation
   pass, to convert one row from untested to a verdict.
3. Leave the key and attempt the K^(1/3) size-elasticity prediction, which has
   never been tried. The cross-sectional version is confounded — measured
   elasticity −0.155 against a predicted −1/3, and the quarterly-snapshot
   overshoot bias is size-correlated and of comparable magnitude. The
   within-bank route using the 235 repeat issuers' own asset growth as a K
   proxy was identified as the likelier path and never attempted.

Option 2 is not recommended: it is mostly infrastructure rebuild for one
verdict on a quantity the model may not be specified to deliver on book data.
Option 3 is the only untried substantive test.

## 9. Derived results worth not re-deriving

The observation model, closing the quarterly-snapshot identification gate.
The stationary density at the trigger vanishes linearly, since s is absorbing
with regeneration — it does **not** approach a positive constant, and the
locally-uniform assumption is rejected flat by ergodic simulation. SymPy-
checked and Monte-Carlo validated to within 4%:

```
E[W]   = (4*sqrt(2)/(3*sqrt(pi))) * sigma(s) * sqrt(dt) = 1.0638 sigma(s) sqrt(dt)
Var[W] = ((27*pi - 64)/(18*pi)) * sigma(s)^2 * dt       = 0.3682 sigma(s)^2 dt
E[D]   = mu(S) * dt / 2
Var[D] = 0.5 * sigma(S)^2 * dt
```

Consequences: the measured gap carries a negative bias of order sqrt(dt);
since σ falls with bank size the bias is smaller for large banks, so the
measured gap *rises* with size, opposing the predicted −1/3. And with s, S
fixed within bank and D ⊥ W,

```
b_pre  = -x * Var[W] / (Var[W] + Var[D])
b_post = +x * Var[D] / (Var[W] + Var[D])
```

which is the identity the shape test rests on. Note `E[D]` requires a
*regenerating* Monte Carlo; an absorbed-cohort simulation gives the wrong
answer.

Durable solve parameters: r=.025, mu_s=.04, mu_L=.03, rho=.12, gam=.02,
sig=.08, sigL=.03, c=.20, kap=.01, K=.02, R=1.15, a1=.045, a2=.05, a3=.30,
rho_L=.09. Derived: kappa1=1.7720, kappa3=0.2623, xbar=1.167647.

a₂ and a₃ have no identified regulatory referent — LCR, NSFR and
transformations of them were searched and none matches, unlike a₁. They stay
unobserved, and it is near-moot since only 2.30% of bank-quarters sit at or
above the model's target.

## 10. Working rules for this project

From the project's own standing directives:

- Keep only what is logically complete and survives scrutiny. No history or
  log character in any shipped file — no retraction or correction narratives.
- Between two entities covering the same ground, keep the provable one.
  Chronology carries no weight. Never keep both in vague coexistence.
- One canonical verifier per claim: Lean where it reaches, SymPy only where it
  does not.
- Every number regenerated from corrected scripts, never carried forward.
- Never edit a canonical analysis script to fit one caller — write a wrapper.
- Deliver ONE self-contained bundle, never a patch tar alongside a full one,
  never loose files scattered beside it. One canonical copy of each file.
- Code: no comments, neither inline nor docstrings. Explanation goes in the
  response, not the file.
- Analytical claims in verifiable form — identity, code, or number — not
  interpretive prose.
- For LaTeX deliverables, supply the compiled PDF with every update.
- Verification infrastructure is not an achievement. Report only substantive
  results toward the stated goal.
- Do not draft paper prose. Suggestions when asked; Lean proofs for what may
  or may not be provable.

Environment facts that keep mattering:

- Octave 7.1.0 on his machine. Never use MATLAB-compatibility shims
  (`csvwrite`, `csvread`); stream via `printf`.
- Solve `.mat` files are Octave **text** format. `scipy.io.loadmat` fails on
  them. `rederive_model_and_data.py` contains a working parser.
- Real solves take roughly 1h50m each and run on his machine only.
- A check whose prerequisites are present but which cannot run is a FAIL,
  never a SKIP.
- When a checker and a document disagree, suspect the checker first. It has
  been the checker twice.
- Verify a new check by mutation before trusting it.
- For table-heavy LaTeX, render to PNG and inspect visually; overfull-hbox
  warnings do not localise header collisions reliably.
