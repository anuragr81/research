## 2. Running the verification locally

### 2.1 Python suites

Needs `sympy`, `scipy`, `numpy`. Verified against sympy 1.14, scipy 1.17,
numpy 2.4, and re-verified 1 Sep 2026 against sympy 1.14, scipy 1.18,
numpy 2.5.

`verify.sh` runs under `pipefail`, so a suite that crashes outright is
caught. Before 1 Sep the exit status of each `python3 ... | tee` pipeline
was `tee`'s, i.e. always 0, so a crashing Python suite would print its
traceback and the run would still report "ALL SUITES COMPLETED" — the same
false-green failure mode as the silent Lean skip below.

```
./verify.sh
```

Runs everything and rewrites `VERIFICATION.md`. Individual suites can be run
directly, e.g. `python3 checks/verify_sympy.py`.

### 2.2 Lean

A missing `lean` is now a **hard failure**: `verify.sh` prints `[FAIL] lean
not on PATH`, reports `SOME SUITES REPORTED FAILURES`, and exits non-zero.
The Lean leg can no longer go unrun unnoticed, which it previously did for
several sessions because the suite was skipped silently while the run still
printed "ALL SUITES COMPLETED".

Core only, no Mathlib, no `lakefile`. The file compiles as a single
standalone unit:

```
lean lean/EntryContest.lean
```

Toolchain: verified on **4.14.0** (original) and **4.33.1** (1 Sep 2026).
The development is not version-fragile — 4.33.1 compiles it unchanged, with
an identical axiom profile (31/31 audited, 20 axiom-free). No pin is
enforced; any recent core toolchain should work, and the core-only,
Mathlib-free design is what buys that latitude.

```
elan toolchain install leanprover/lean4:v4.33.1
```

Install note: if `elan` cannot resolve `release.lean-lang.org` from a
sandbox, the direct GitHub tarball works and is recorded in `verify.sh`'s
failure message:

```
curl -sL -o lean.tar.zst \
  https://github.com/leanprover/lean4/releases/download/v4.33.1/lean-4.33.1-linux.tar.zst
tar --zstd -xf lean.tar.zst
export PATH=$PWD/lean-4.33.1-linux/bin:$PATH
```

### What is *not* established

Stated plainly because it is easy to overstate what a green suite means.

1. **Nothing is machine-checked end to end from primitives.** Every Lean
   theorem is a conditional deduction. The development is deliberately
   confined to discrete and order-theoretic content because Mathlib is not
   used; all analysis enters as hypotheses.

2. **Three analytic inputs are assumed, not proved.**
   - `step_nonpos` — the sign of the step difference, the engine of P3-cor
     and hence P5. Discharged at tier S by S1–S6.
   - `kappa -> infinity` at the support floor, needed for P9-strict.
     Discharged at tier S by S16, and now stated as an assumption in
     §Primitives.
   - Monotonicity of the integral functional, needed for P7 (`H_m <= F^m`
     pointwise to `Int H_m dF <= Int F^m dF`). Not discharged anywhere; it
     is the same hypothesis already supplied explicitly in the Lean
     development for P2, so it is not a new assumption.

4. **P7 is not verified end to end, deliberately.** Evaluating the
   conclusion `Delta(m) <= V/(m+1)` over the admissible power families is
   uninformative: `max (m+1)*Delta` is about 0.46 there and about 0.79 over
   a widened set, so the tighter caps `1/(m+2)`, `1/(m+3)` and `1/(m+4)`
   pass on every case too. A test that cannot separate the true bound from
   a tighter false one is not evidence for it, so S18–S20 verify the proof
   steps instead. The quadrature block in `verify_p679.py` is corroboration
   and carries the same caveat. Do not "strengthen" P7 by adding the
   end-to-end comparison; it was tried and rejected.

3. **P-MU caveat.** S11 shows the weight `W = G^(Q-1)(1-G)F` is hump-shaped,
   so FOSD cannot *determine* the sign. It does **not** show both signs
   occur: S12 evaluates the integral exactly over the admissible power
   family `F = x^k, G = x` subject to `F <= G` and finds one sign in all 15
   pairs. The sign reversal refuting R2 is exhibited in `verify_p89.py` on
   the model's induced `F, G`, which are not power functions. An earlier
   draft overstated this; the correction is recorded in `PROOFS.tex`.

## 4. Where the paper stands against the referees

Six consolidated findings from the referee record. Four addressed, one
partly, one open.

1. **Equilibrium concept** (R1.1, R2.1) — addressed. P3/P5 replace
   aggregate-regime comparison with unilateral deviations and an interior
   count. The complete-information assumption this rests on is now stated
   in §Primitives, which was the gap.
2. **Prize/affordability conflation** (R1.5, R2.2) — addressed. `V` is
   exogenous and fixed; affordability runs only through `kappa`.
3. **No welfare benchmark** (R2.3) — **OPEN. Nothing written.** See §5.
4. **Ceiling is an artifact** (R1.4, R2.4) — addressed. P7's uniform cap
   replaces it; no asymptotics anywhere. The author's own conjectured
   collapse threshold was refuted (R1) in the process.
5. **Contribution not located** (R1.4) — addressed in `LITERATURE.tex`, but
   **not yet in `PROOFS.tex`**. See §5.
6. **Distributional generality** (R1.3) — moot by the standing
   distribution-free decision.

Still open from R2.1: the incumbent's entry is exogenous, so the referee's
question about an equilibrium where the incumbent abstains and a challenger
invests is untouched. Lazear–Rosen §IV handicap algebra is the tool.

## 5. Next steps, in order

**Read `SOUNDNESS_20260902.md` first — it reorders everything below.** An
adversarial pass on the central chain found: (1) the identity-pinning claim
is false (verified counterexample; three equilibria on one instance, richest
absent in one of them; multiplicity in 17.3% of 20,000 random instances) —
but the *count* is unique across all pure equilibria, a provable
strengthening of P5 not yet formalised; (2) the agent's utility function is
never displayed (implicit privilege-contest form `u(w−ce) + V·1{win}`);
(3) wealth-independence of the score draws is implicit but load-bearing for
`prop:anon`. P9-gen survives all three (it is a count statement). The
repair plan in that report precedes the welfare section and the research
leads.

**Then read `lit/TRACEABILITY.md`.** The literature-verification pass (twelve
paper directories under `lit/`, 70 checks, all green via `lit/verify_lit.sh`)
audited every relevance claim the survey makes against the sources and against
`PROOFS.tex`. Its consolidated action lists supersede the details below where
they conflict — in particular: item 1's Levin–Smith frame must use the
corrected reading of their eq. (9) (planner's FOC, not a reservation
condition); item 2's positioning edits now include the P7 attribution (FJL
Definition 2 + Fu–Lu eq. (7)), a CMP citation at `V`, and RD provenance for
P-MU's weight; item 3's proposed log-concavity route is misattributed to
Costrell–Loury, whose Prop 5 needs only a non-decreasing weight — try that
weaker route first, and mind Suen fn. 1's rank-rescaling trap; item 4 is done
(computed: the kernel identity is exact, log-supermodularity transfers, the
single-crossing orientation is reversed — no unimodality claim available).

1. **Welfare section.** The only referee finding with nothing behind it.
   The reading is done and the frame is identified: Levin–Smith Prop 3
   (fixed prize is common-value-like, so free entry is excessive by
   business-stealing), Becker–Murphy–Werning §7 (rank-allocated status
   carries real externalities that purchased status does not),
   Cole–Mailath–Postlewaite 1995 §4 (welfare theorems do not apply to
   prizes allocated by rank), Chung–Lee 2017 as a worked template. State an
   objective, show `mu = 1` and prohibitive `c` as first-best corners,
   argue why they are unattainable, then compare interior policies.

2. **Fold the positioning into `PROOFS.tex`.** Three specific edits, all
   sourced in `LITERATURE.tex`:
   - contribution sentence: *moving the choice from the intensive to the
     extensive margin makes the mean-preserving-spread comparative static
     sign-determinate without higher-order restrictions on utility*;
   - acknowledge Lazear–Rosen (1981) §III "Income Distributions" as the
     precedent for wealth-based self-selection into a contest, naming the
     channel difference (`u''` here, `u'''` there);
   - cite Cole–Mailath–Postlewaite 1992/1995 where `V` is introduced, since
     they justify a rank-allocated non-market prize.

3. **Open item 2 — general spreads.** P9-gen requires a pivot-spread. Suen
   (2007) Prop 2 and Costrell–Loury (2004) Prop 5 both sign an aggregate
   under a *general* Rothschild–Stiglitz spread with arbitrary finite
   crossings, sharing a quantile-difference decomposition — but **not the
   same hypotheses, and not independently**: Suen cites Costrell–Loury for
   the quantile-reversal step. Costrell–Loury's Prop 5 needs only a
   **non-decreasing weight** (no concavity, no log-concavity, no hazard
   rate anywhere in that paper); Suen adds concavity plus log-concavity of
   `1-F`. **Try the Costrell–Loury monotone-weight route first**, not
   log-concavity of `1 - Lambda`.

   Three obstacles, all recorded in `lit/TRACEABILITY.md` §5: the
   aggregate/count gap (both sign smooth integrals, `k*` is an integer
   threshold count — the substantive one); the rescaling trap (writing `k*`
   via `kappa o Lambda^-1` is exactly what Suen's fn. 1 declines, since
   curvature does not survive rank-rescaling unless the density is
   increasing); and cross-side vs same-side. Untried; do not claim until
   tried.

4. **P-MU and Ryvkin–Drugov — DONE, computed.** The correspondence is exact:
   P-MU's weight `W = G^(Q-1)(1-G)F` contains RD's log-supermodular kernel
   `F^(k-1)(1-F)` under `G <-> F`, `Q <-> k`, so S11's hump at `(Q-1)/Q` *is*
   their kernel at `(k-1)/k`. Log-supermodularity transfers; the
   single-crossing orientation does **not** (ours crosses `-+`, Karlin needs
   `+-`). **No unimodality claim for `Delta(0,Q)` is available.** Note also
   that the right comparator is their *density* result `b_k`, not the
   hazard-rate result, which governs aggregate effort. Remaining lead: work
   out the `-+` orientation (plausible target, an interior *minimum*), or
   read RD Appendix A.2's `TP_r` machinery, which is unread and covers
   multimodal cases. See `lit/ryvkin_drugov_2020/NOTES.md`.

5. **Utility-function experiments** (author's own direction, deferred until
   the above are settled). Note the design constraint discovered in the
   literature work: making `V` money added to the resource moves the model
   from Schroyen–Treich's *privilege* contest to their *rent-seeking*
   contest, where the two wealth effects oppose and, under CARA, exactly
   cancel. That is a substantive model change, not a robustness tweak.

### If Mathlib is added

Optional and not required for any current claim. It would let
`step_nonpos` and the `kappa` divergence be proved rather than assumed,
collapsing the S tier into L and making the chain machine-checked from
primitives. Cost: a `lakefile`, a Mathlib pin, and a much slower build. The
present core-only design is a deliberate trade and should not be changed
casually — the explicit-hypothesis style is what makes the dependency on
the analytic inputs visible.

## 6. Conventions

- One self-contained bundle per delivery; no overlays or patch tarballs.
- No duplicate copies of a file inside the bundle.
- Code carries no comments; explanation lives in `PROOFS.tex` or here.
- `VERIFICATION.md` is generated — never hand-edit.
- Every literature citation needs author, title, journal, year, volume and
  pages verified against a title page, publisher page, or published
  reference list, with full-read versus abstract-level tagged [F]/[A]/[C],
  and working-paper reads marked as such.
